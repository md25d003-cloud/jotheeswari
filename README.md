# Jotheeswari Murali Academic Website

## Quick start
1. Open `index.html` in a browser to preview the website.
2. Your IIT Madras email is already added: `md25d003@smail.iitm.ac.in`.
3. Your uploaded profile photo is already included as `images/profile.jpg`.
4. Your LinkedIn profile is already linked in the Contact section.
5. Add your Google Scholar and ORCID URLs when available.
6. Add your CV as `documents/CV.pdf`.

## Publish for free with GitHub Pages
1. Create a GitHub account if you do not already have one.
2. Create a repository named `jotheeswari.github.io`.
3. Upload all files and folders from this package.
4. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
5. Your site will become available at `https://jotheeswari.github.io/`.

## Before publishing
- Confirm your official IIT Madras department name.
- Confirm your degree names and dates.
- Add your supervisor/lab details if desired.
- Add publications only after checking the final citation details.
- Replace placeholder contact/profile links.
